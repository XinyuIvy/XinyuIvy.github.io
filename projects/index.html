AI Usage Dashboard — Cross-Device AI Quota Observability ↗

I built a privacy-aware dashboard that consolidates quota usage, reset windows, and account status across multiple AI coding services. A Python REST service normalizes provider data for a responsive web dashboard, macOS menu-bar display, and iPhone widget, while caching, last-known-good fallbacks, and stale-state labels preserve useful status during partial failures. Credentials remain on the authenticated Mac, with read-only quota information delivered privately across devices.
